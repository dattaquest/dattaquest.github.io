Buscar radicación de patente

Formatos usuales para autos: ABC123 y AB123CD. La consulta oficial de DNRPA requiere un código verificador. Con una API autorizada configurada, esta página puede mostrar resultados.

Información del servicio

  • La jurisdicción de radicación no puede obtenerse de forma fiable interpretando la patente.
  • Se requerirá información actualizada de DNRPA mediante un mecanismo habilitado.
  • Este formulario no consulta propietarios ni revela datos personales.

La radicación puede modificarse. No se infiere de manera fiable a partir de las letras de la patente.
