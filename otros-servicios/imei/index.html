Verificador de IMEI

Validá el IMEI e identificá marca y modelo mediante una base TAC abierta. El bloqueo requiere una fuente autorizada.

Verificar IMEI, marca y modelo

Encontralo marcando *#06#. La validación funciona localmente. El catálogo TAC se descarga sin enviar tu IMEI; el bloqueo necesita una API autorizada.

Información del servicio

  • Comprueba longitud y dígito de control mediante el algoritmo Luhn.
  • Busca marca y modelo por TAC en la base comunitaria Osmocom (CC-BY-SA 3.0), sin enviar el IMEI completo.
  • Una verificación de lista negra por robo o extravío requiere conexión con una fuente autorizada.
  • Un resultado válido no confirma que el dispositivo no esté bloqueado.

Un IMEI matemáticamente correcto o un TAC identificado no garantiza que el equipo sea legítimo o que no esté denunciado. Datos Osmocom (© Harald Welte y colaboradores, CC-BY-SA 3.0).
