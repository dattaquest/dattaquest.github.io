Buscador de prestadores

Consultá el prestador original de un bloque telefónico y, cuando esté disponible, su prestador actual.

Consultar prestadores

Admite +54, 0 inicial y espacios. No se consultan nombres ni datos del titular.

Información del servicio

  • Consultá el prestador original, la marca comercial asociada y el bloque numérico.
  • El prestador actual aparece cuando la consulta puede confirmarlo.
  • Admite números con código de país y prefijo de celular.
